# Lashes block builder

Builds a Lashes message block for Rise — her, a line, and a button.

Open `lashes-builder.html` in a browser. Choose her expression (Encouraging, Heads
up, Tip, Plain), put her left or right of the message, write the text and the button
label, then **Download index.html** or copy the code out. There is a Launcher mode
for the Begin-card shape as well.

**No build step**: the HTML is the source.

## The thing to know before editing her

Her drawing is duplicated. It lives here, in the lesson template, and in each
knowledge-check staging — the same geometry and the same expression library, copied
rather than imported, because every one of those pages has to stand alone with no
network. **If her face changes, it has to change in all of them**, and this tool is
the obvious place to extract a single source from when somebody has the appetite.
